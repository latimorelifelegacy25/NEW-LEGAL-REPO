# Offline Law Manifest

These files are dated offline fallbacks from the audited `pa-litigation-command` package. They are useful for navigation and continuity when current official sources are unavailable, but they do not certify current law.

The source build contained text snapshots and source PDFs for Title 18, 23 Pa.C.S. Chapter 43, 42 Pa.C.S. Chapter 63, the Pennsylvania Constitution, and 231 Pa. Code Chapter 200. The operational GitHub source tree may omit large binary source PDFs; the integrated release package retains them.

Before filing, verify the current official law and actual source document.
