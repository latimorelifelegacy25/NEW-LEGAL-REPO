# Legal OS privacy boundary

This repository is code-only and is currently public.

Do not commit private matter data.

## Public repository may contain
- application source code
- schemas and migrations
- tests using synthetic fixtures
- non-confidential workflow definitions
- non-secret configuration examples

## Must remain outside the public repository
- Second Amended Complaint and prior pleadings
- exhibits and evidence
- CYS records
- personal correspondence
- discovery responses containing private information
- generated matter artifacts
- credentials, API keys, OAuth tokens, service secrets
- private Pennsylvania reference corpora unless redistribution is authorized

The application should load private matter data from authenticated private storage at runtime.
